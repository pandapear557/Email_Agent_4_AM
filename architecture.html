1 동작 흐름 (Pipeline)

① 입력

텍스트 추출

parse_input()

DocX / MD / TXT 업로드 → 본문 텍스트 추출. python-docx로 문단 파싱.

➜
② 초안

Claude 작성

draft_email()

회의록 + 맥락 + 사이드바 지침(system) → Claude API → 메일 초안(Markdown).

➜
③ 서식

Gmail HTML

format_gmail_html()

Markdown → 인라인 스타일 HTML. Gmail이 <style>을 떼므로 인라인으로.

➜
④ 운용

현황 대시보드

st.session_state.runs

실행마다 기록 적재 → 지표·이력·초안 다시보기. 결과는 '검토 대기'(발송 X).

입력 초안(Claude) 서식 대시보드(불변층)

2 핵심 설계 원칙

🔌 엔진 교체 가능 · 대시보드 불변

3개 단계 함수는 독립 시그니처를 유지한다. 지금은 이 앱이 직접 돌리지만(v1), 나중에 1~3단계를 n8n으로 옮겨도 대시보드(④)는 그 상태만 읽어 그대로 표시 — 화면은 안 바뀐다.

parse_input(file) → str draft_email(notes, ctx, model) → str format_gmail_html(md) → str

🧍 사람이 마지막 게이트

파이프라인은 '초안까지'만 자동. 메일 발송은 자동화하지 않음. 그래서 완료 상태가 '완료'가 아니라 '검토 대기'. 현재 실제 초안 작성은 Claude Desktop에서 수제작 중 → 앱은 대시보드/서식 역할 우선.

5 기술적 제언 (Technical)

T1 · 이력 영구 저장 (가장 큰 구멍)

HIGH

지금: 이력이 session_state라 새로고침하면 사라짐 → 대시보드의 "운용 기록" 가치가 0이 됨. 제안: Google Sheet(무설정·무료) 또는 Supabase에 runs append. Streamlit Cloud 파일시스템은 재시작 시 초기화되니 SQLite 파일은 부적합. 난이도 낮음, 효과 큼 → 1순위.

T2 · 키 없는 '미리보기 모드' 명시화

MID

키 미설정이면 "새 초안 만들기" 버튼을 비활성화하고 왜 막혔는지 안내(현재는 누른 뒤에야 에러). 지금처럼 Desktop 수제작 단계엔 "초안 붙여넣기" 입력칸을 두면 키 없이도 ②를 사람이 채우고 ③ 서식·④ 대시보드를 그대로 쓸 수 있음 → 앱이 당장 쓸모가 생김.

T3 · 입력 견고성 (PDF·HWP·인코딩)

MID

이력 예시에 스캔본.pdf가 '실패'로 찍혀 있음 — 현재 DocX/MD/TXT만 지원. 한국 업무 환경이면 PDF·HWP(한글) 수요가 큼. parse_input 앞단만 확장(pdfplumber 등). 빈 파일·깨진 인코딩 가드도 추가.

T4 · 서식 변환 안전성

LOW

format_gmail_html의 문자열 .replace() 치환은 코드블록·표·중첩 리스트에서 깨질 수 있음. 장기적으로 bleach 살균 + 화이트리스트 인라이너로. 지금은 동작 OK라 우선순위 낮음.

6 기능적 제언 (Functional)

F1 · 지침 프리셋 (수신자별 톤)

MID

사이드바 지침이 시스템의 진짜 가치인데 지금은 단일 텍스트 1개. "상사용/고객용/팀내부용" 프리셋을 드롭다운으로 저장·전환하면 회의록마다 톤을 즉시 바꿀 수 있음.

F2 · 초안 재생성 & A/B

LOW

"다시 생성"(같은 입력, 다른 표현) 버튼과 2안 비교. 메일은 표현 미세조정이 잦아 효과 큼. 이력에 버전으로 묶어 보관.

F3 · 원클릭 Gmail 초안 (로드맵 1순위)

MID

현재는 HTML 내려받아 수동 붙여넣기. Gmail API(OAuth)로 임시보관함에 초안 자동 생성까지. 발송은 끝까지 사람이 — 설계 원칙 유지. 단, OAuth 시크릿 관리 필요해 키 준비된 뒤 단계.

F4 · '검토 대기 → 발송됨' 상태 마감

LOW

실제로 보낸 초안에 사람이 체크 → '발송 완료' 표시. 그래야 대시보드의 '완료' 지표가 의미를 가짐(지금은 항상 0). 운용 도구로서의 완결성.

★ 한 줄 요약

구조는 깔끔하게 분리돼 있어 확장 준비는 끝났다. 지금 당장 가장 효과 큰 한 수는 T1(이력 영구 저장) — 그래야 '대시보드'가 진짜 운용 기록이 된다. 그리고 키 없는 현 단계엔 T2(초안 붙여넣기 입력)를 더하면 Claude Desktop 수제작 흐름과 이 앱이 곧바로 맞물린다.
